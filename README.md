# Pharma Dose Calculator
A Python program that estimates drug doses using mg/kg weight-based dosing, with a drug database and a maximum-dose safety check.

Built as a learning project by a B.Pharm student. Not for clinical use. Dose values are examples only.

## How to run
Open the code in Google Colab or any Python environment and run it. Enter the patient name, weight, and drug name.

## Skills used
Python, dictionaries, functions, conditionals, user input
